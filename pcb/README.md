# PCB Design

KiCad project files for the AeroGyro hardware.

## Structure

- `schematic/` - KiCad schematic files
- `pcb-layout/` - KiCad PCB layout files
- `footprints/` - Custom component footprints
- `symbols/` - Custom schematic symbols
- `manufacturing/` - Gerber and drill files for fabrication
- `3d/` - 3D model exports
